# Checklist

Before coding:
- [ ] Is the task actually asking for code changes?
- [ ] What is the smallest relevant file set?
- [ ] What must not be touched?

During coding:
- [ ] Keep the diff narrow.
- [ ] Avoid unrelated cleanup.
- [ ] Prefer explicit, boring code over clever abstractions.

Before final response:
- [ ] Run or name the most relevant verification command.
- [ ] Mention unverified claims as unverified.
- [ ] List remaining risks briefly.
